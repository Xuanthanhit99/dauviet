# DẤU VIỆT GLOBAL — PHASE 04
## Iconography & Semantic Symbol System V1.0

### Status
**PRODUCTION CANDIDATE**

### Core grammar
Default grid is **24×24**, with a **1.75 px optical stroke** and rounded caps/joins. Compact/mobile glyphs may use 2 px. Functional icons are restrained and editorial rather than decorated with pseudo-historical ornament. The Time Trace logo is never reused as a generic UI glyph.

### Domain semantics
- **Place:** landform/spatial abstraction.
- **People:** human/profile abstraction.
- **Event:** occurrence/time pulse.
- **Culture:** interlocking/woven relationship.
- **Time:** temporal arc.
- **Source:** document/evidence record.
- **Story:** open narrative.
- **Journey:** route with nodes.

### Trust & provenance
Citation, Evidence, Verified, Reconstruction, AI Translation, Warning and Sensitive-content indicators require explicit accessible semantics. Reconstruction and AI translation must expose disclosure text whenever a user could mistake transformed/generated material for documentary evidence.

### Map contract
Spatial pointer geometry is allowed **only as a map utility container**; it is not a Dấu Việt brand motif. Inner glyphs distinguish semantic categories. Selected markers add outline/scale; Visited adds check/stamp plus state; clusters always display a number.

### Accessibility
Simple utility icons may render at 16 px; domain/semantic glyphs prefer 20–24 px. Interactive controls target **44×44 CSS px**. Essential graphics target at least **3:1** contrast. Non-obvious standalone icon buttons require accessible names. Color-only and motion-only meaning are prohibited. Focus inherits the Production-Locked Phase 02 system.

### Compatibility with locked product design
This phase supplies a semantic grammar, not permission to redesign previously locked components. Existing Map, Story Explorer, Journey, Connection and Evidence/Trust components should map into these semantics with the minimum visual change necessary.
