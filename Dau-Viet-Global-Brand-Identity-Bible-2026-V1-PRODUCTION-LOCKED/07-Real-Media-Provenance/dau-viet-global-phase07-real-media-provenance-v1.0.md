# DẤU VIỆT GLOBAL — PHASE 07
## Photography, Real Media & Provenance Visual System V1.0

### Status
**PRODUCTION CANDIDATE**

This phase turns the already locked Real Media + Provenance Policy into a production visual system. The governing principle is simple: **truth and provenance outrank visual similarity, aesthetic convenience and empty-state pressure.**

### Media classes
1. **Documentary Photo** — correct entity, source/provenance, rights/license, capture date/period when known.
2. **Archive** — archive/source, creator when known, date/period and rights/public-domain status.
3. **Artifact / Record** — holding institution/source, object/document identity, rights and date when known.
4. **Historical Map** — source, date/edition, creator/publisher when known and rights.
5. **Reconstruction** — explicit disclosure, basis/sources, creator/method and rights. It is visually differentiated from documentary evidence.
6. **AI-generated** — explicit disclosure, purpose and generation/editorial provenance. It is **never evidence**.
7. **Illustration** — creator/source, rights and editorial role.
8. **Community Contribution** — contribution context, rights/consent, moderation status and supplied capture metadata.

### Provenance contract
Every production asset requires a `MediaAsset` identity, correct entity/content relation, media class, source/provenance, rights/license and editorial status. Creator, dates, institution/archive, location, archive reference, transformation history, reconstruction basis and AI disclosure are conditional but become mandatory when relevant.

**Frontend renders provenance supplied by backend/CMS. It never invents, guesses or infers missing provenance.**

### Photography direction
Prefer natural light, authentic atmosphere, human scale and geographic/cultural specificity. Avoid generic luxury-travel stock aesthetics, heavy teal/orange grading, fake film damage, AI surrealism, excessive HDR and tourism-ad clichés. Color grading may create restrained tonal coherence but must preserve documentary truth.

### Crop & ratio system
- Hero: 16:9 or cinematic responsive crop with a protected focal region.
- Destination card: 4:3 preferred.
- Place/Story card: 3:2 or 4:3.
- Person portrait: 4:5.
- Artifact/record: native ratio preferred; do not force-crop evidence.
- Then & Now: matched viewpoint/anchor where possible; mismatch is disclosed rather than hidden.

### Then & Now
Prefer a real historical/archive image paired with a real contemporary image. Align viewpoints only when evidence supports the match. If date, viewpoint or spatial extent differs, disclose it. A reconstruction can never silently occupy the historical side as though it were a documentary photograph.

### Transformation policy
Normal technical processing includes resize, responsive crop, compression, format conversion and orientation correction. Restrained exposure/color normalization is acceptable. Material transformations such as restoration, compositing, colorization or AI-assisted reconstruction require provenance records/disclosure where relevant.

For documentary presentation, prohibit fabricated people/objects, invented historical scenery, materially altered architecture/artifacts, undisclosed generative fill and misleading weather/sky replacement.

### Missing-media fallback
Missing media is not permission to use the wrong image. Use a designed no-media state, map/context graphic, verified text/story treatment or provenance-safe placeholder. Never scan local/public folders for a visually similar asset, randomize imagery, use another entity's image or insert unlabeled AI media.

### Accessibility
Meaningful images receive useful alt text describing visible content and relevance; decorative images use empty alt only when truly decorative. Evidence-sensitive media keeps caption/provenance available nearby. Text overlays obey the locked Phase 02 contrast rules. Artifact/document imagery supports closer inspection where the product context requires it.

### Compatibility with locked baselines
This phase does not redesign Home V5, Explore Map V3, Destination/Place/Story/Journey or the existing Real Media + Provenance Policy. It supplies the visual and metadata presentation rules required to implement them consistently.
