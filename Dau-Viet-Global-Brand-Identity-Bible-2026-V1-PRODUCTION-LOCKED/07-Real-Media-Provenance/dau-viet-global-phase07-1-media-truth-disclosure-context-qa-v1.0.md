# DẤU VIỆT GLOBAL — PHASE 07.1
## Media Truth, Disclosure & Context QA V1.0

### Result
**PASS WITH IMPLEMENTATION RULES — READY FOR PHASE 07 PRODUCTION LOCK**

Phase 07 remains valid across Hero, Destination, Place, Story Explorer, Then & Now, Person, Event, Artifact/Source and Community contexts. No visual-system redesign is required. The lock gate is provenance correctness and disclosure behavior, not aesthetic similarity.

### Surface QA
**Hero — PASS WITH RULE.** Hero may prioritize emotion and cinematic composition, but it may never use a visually similar wrong-location image. Protected focal crops and readable overlays must not remove critical documentary context.

**Destination Card — PASS.** Correct entity relation is mandatory. Cards may expose less metadata visually, but provenance remains retrievable through the relevant detail/context.

**Place Detail — PASS.** Primary media belongs to the actual place. Nearby or stylistically similar architecture is not a valid substitute. Documentary and reconstructed media remain distinct.

**Story Explorer — PASS WITH RULE.** Immersive atmosphere cannot blur documentary evidence with illustrative atmosphere. Evidence identity, source and citations remain available.

**Then & Now — PASS WITH RULE.** Truth outranks perfect visual alignment. Viewpoint/date/spatial mismatch is disclosed. Reconstruction never silently occupies the historical side.

**Person — PASS.** Identity is verified. Generic or lookalike historical portraits are prohibited. Illustration/reconstruction is labeled.

**Event — PASS WITH RULE.** Images actually depicting the event are distinguished from later images of the same location, memorials, reenactments or commemorations.

**Artifact / Source — PASS.** Native ratio and evidentiary detail outrank card consistency. Inspection/zoom is supported where needed.

**Community — PASS WITH RULE.** Contribution, rights/consent and moderation context remain attached. Community media does not become editorially verified merely because it appears next to verified content.

### Cross-system QA
Correct entity relation passes as a hard requirement. Rights/license is required before production publication. Reconstruction and AI-generated media remain explicitly disclosed; AI-generated media is never evidence. Material transformations are recorded/disclosed where relevant. Missing media uses designed fallbacks only. Accessibility requires useful alt text, nearby evidence provenance/captions and inspection support for document/artifact contexts.

### Required production rules for lock
1. Every production asset resolves to the correct `MediaAsset` and correct entity/content relation before publication.
2. Hero/card aesthetics never permit wrong-location, wrong-person, lookalike or random substitution.
3. Evidence-sensitive media keeps provenance/caption retrievable near the viewing context; immersive layouts cannot hide evidence identity.
4. Reconstruction, AI-generated, illustration and material restoration/colorization are explicitly classified/disclosed where confusion with documentary evidence is possible.
5. Then & Now discloses viewpoint/date/spatial mismatch and never silently uses reconstruction as historical photography.
6. Event media distinguishes actual-event imagery from later place imagery, memorials and reenactments.
7. Artifact/source presentation preserves evidentiary detail and native ratio where needed; destructive crop for card consistency is prohibited.
8. Community media retains contribution/moderation/rights context and never inherits editorial verification by proximity.
9. Missing media uses a provenance-safe designed fallback. Folder scanning, random imagery and visually similar substitutes are prohibited.
10. Frontend never invents provenance. Missing source/rights/classification is a CMS/editorial data issue, not a UI inference task.

### Decision
Phase 07 is **READY FOR PRODUCTION LOCK** with these ten production rules included in the baseline.
