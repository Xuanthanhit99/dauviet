## Semantic

Reconstruction identifies reconstructed or interpretive visual/content material that must carry explicit disclosure whenever it could be mistaken for documentary evidence.

Reconstruction is not Evidence, Citation, Source, Verified, AI Translation, Warning, or Sensitive.

## Canonical metaphor

**Layered Frame + Offset Trace**

- Layered Frame = multiple temporal/source layers used to form a reconstruction.
- Offset Trace = the visible separation between the retained trace and the reconstructed layer.
- The glyph must communicate reconstruction/disclosure, never verification or documentary originality.

## Prohibited semantics

No checkmark, sparkle/AI star, Evidence document+lens, Citation reference brackets/source point, warning triangle/exclamation, shield, map pin, logo reuse, or color-only meaning.

## Candidate geometry gate

This lock authorizes the metaphor and system construction. Exact SVG path coordinates remain a separate deterministic candidate-construction step and must preserve the Layered Frame + Offset Trace metaphor. Exact geometry must be recorded before a candidate may advance to human visual approval.

No production distribution is authorized by this construction lock.
